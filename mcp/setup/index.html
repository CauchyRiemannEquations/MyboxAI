내 MYBOX를 AI에 연결하세요.

복잡한 명령어 대신, 앱을 고르고 토큰을 한 번 입력하면 됩니다.

1 사용할 앱 선택

여러 앱을 함께 연결할 수 있습니다. 선택한 앱의 기존 mybox 항목은 교체합니다.

변경할 설정 파일 보기


2 MYBOX 토큰 발급 및 입력


MYBOX 환경설정 열기 ↗ · 공식 발급 안내 ↗


  1. 네이버 로그인 후 계정 및 개인 액세스 토큰 관리를 누릅니다.
  2. 개인 액세스 토큰 생성에서 이름과 유효기간을 선택합니다.
  3. 생성된 토큰을 바로 복사해 아래에 붙여 넣습니다. 토큰은 생성할 때 한 번만 표시됩니다.


유효기간을 꼭 확인하세요.
네이버 생성 화면에서 30일 · 60일 · 90일 · 180일 중 선택하세요. 표시되는 만료일도 확인해 두세요. 만료 전에 새 토큰을 발급해 이 화면에서 다시 연결하면 됩니다.


위 순서로 발급한 토큰을 입력해 주세요.
연결하면 토큰을 이 PC의 전용 파일에 저장합니다. 토큰은 네이버 API에만 보내며, 채팅에 붙여 넣을 필요가 없습니다.


연결한 앱에서 MYBOX 파일 읽기·업로드·이름 변경·이동·삭제를 사용할 수 있습니다. 영구 삭제와 휴지통 비우기는 별도 작업입니다.


설치 정보를 확인하고 있습니다.


문서 읽기부터 파일 관리까지
MYBOX PAT 하나로
PDF·한글·Word와 스캔을 읽고, 파일 업로드·수정·폴더 정리·삭제·복원을 요청하세요. 즐겨찾기와 휴지통 관리도 지원합니다.
Codex·Claude·Gemini의 로그인과 이용 한도는 각 앱에서 관리합니다. 별도 AI API 키는 필요 없습니다.
